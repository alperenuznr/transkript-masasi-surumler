# Transkript Masası — sürümler

Podcast BPT ekibinin kullandığı, tamamen bilgisayarda çalışan transkript uygulamasının sürüm dosyaları.

- Kurulum: son sürümün sayfasındaki `.dmg` dosyasını indirin, açın ve uygulamayı Uygulamalar klasörüne sürükleyin.
- Uygulama bir lisans kodu ister; kodu ekipten alın.
- Kurulu uygulama yeni sürümleri buradan kendiliğinden bulur.

Kaynak kod bu depoda değildir.
